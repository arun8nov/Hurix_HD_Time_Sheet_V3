1. Requirement Analysis
Management's Proposed Monitoring
  • Keystroke & Mouse Velocity: Continuous hardware input logging to detect active vs. idle states.
  • PC Application & URL Tracking: Continuous daemon recording of every opened window title & website domain.
  • Screen Recording / Screenshots: Automated periodic desktop captures stored in cloud vaults.
  • Auto Idle Break Locks: Force-locking endpoint desktops after 3 minutes of inactivity.
Actual Operational Business Requirements
  • Shift & Attendance Verification: SSO-authenticated daily Clock-In and Clock-Out records for 80+ employees.
  • Break Accountability: Explicit tracking of Tea, Lunch, and Personal breaks to avoid untracked shift loss.
  • Task Output & Timesheets: Project task allocation, billable hours, and daily deliverable unit counts.
  • Proof-of-Work Attachments: Uploading milestone documents or screenshots to Shared Google Drive folders.

3. Technical & Resource Feasibility Analysis
Full Surveillance Resource Demand

High infrastructure and administrative consumption:

  • Storage: Screen grabs require 4 GB/day → ~1.4 TB/year.
  • Bandwidth: Continuous screenshot streaming consumes 20-30 Kbps per PC.
  • Licensing: SaaS commercial licenses ($5-$15/user/month).
  • Endpoint Drag: Background daemons consume 15-20% CPU & RAM.
Hurix Built Solution Resource Demand

Zero-footprint, cloud-native serverless architecture:

  • Storage: Text database stored in native Google Sheets ($0).
  • Bandwidth: Microscopic JSON payloads (< 50 KB per action).
  • Licensing: $0 additional cost; runs on existing Google Workspace.
  • Endpoint Drag: Zero. Pure web browser execution.
