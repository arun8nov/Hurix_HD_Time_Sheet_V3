1. User View Scorecards & Meters

UI Meter / Card What It Is For (Purpose) Calculation & Logic
Live Shift Duration Timer Provides associates live visibility into elapsed working time on shift today. Live Timer = (Current Timestamp - Clock In Time) - Total Breaks. Increments every second.
Break Duration (userBreakMins) Accumulated break minutes today to ensure compliance with shift pause limits. Sum of all closed break durations plus active ongoing break timer from Break_Logs.

Logged Task Hours Total duration across all submitted task work entries today. ∑ actual_worked_hours across all rows in user's task log table.
Earned Hours Standard output revenue credit produced based on completed deliverables. (Task Units Completed × AHT Benchmark Mins) / 60. (Bench tasks earn 0.00 hrs).
Performance Leakage Output shortfall between actual task time spent and earned benchmark credit. Max(0, Task Duration - Earned Hours - Blocked Hours). Blockers are deducted.
Speed Efficiency % Visual pace badge (⚡ $\ge 100\%$, ⏱️ $80-99\%$, 🐢 $<80\%$).< /td> Round((Earned Hours / Logged Task Hours) × 100)%.

2. Master Mathematical Formula Index (All Dashboards)

1. Net Worked Hours (Shift Hours)
Net Worked = (Shift End - Shift Start) - (Total Breaks Mins / 60)

Actual physical shift time spent on the floor. (Full Day Leave = strictly 0.00 hrs; Half Day Leave capped at ≤ 4.50 hrs max).

2. Billable Earned Hours (Standard Output)
Earned Hours = (Completed Task Units × Benchmark AHT Mins) / 60

Authorized standard billable revenue output produced. (Bench tasks and Downtime tasks strictly generate 0.00 hrs).

3. Performance Leakage (Output Deficit)
Leakage = Max(0, Actual Task Duration - Earned Hours - Blocked Hours)

Pacing loss between time spent and units delivered. Blocked minutes for client queries are deducted to ensure fair employee scoring.

4. Speed Efficiency % (Benchmark Velocity)
Speed Efficiency % = Round((Earned Hours / Actual Task Hours) × 100)%

Pacing index: ⚡ ≥ 100% High Speed   ⏱️ 80-99% Target Pace   🐢 < 80% Below Pace

5. Floor Shrinkage Rate %
Shrinkage % = (Total Leaves / Total Floor Staff Capacity) × 100

Where Total Leaves = PL + UL + (0.5 × HL) + ABSENT. Evaluates lost capacity across the floor.

6. Pending / Yet to Clock In Staff
Pending = Total Staff (78) - Clocked In (54) - On Leave (12) = 12

Strict balance verification ensuring active floor headcount always adds up to 78 resources.

Column Name Data Type Description & Formulas

Column Name Data Type Description
